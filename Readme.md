# 💌 Our Little Corner

Website cevin untuk memberikan kasih sayang

---

## Fitur Saat Ini

- 🎵 **Background Music Player**: Pemutar audio terintegrasi untuk menemani pengalaman membaca.
- 💌 **Personal Notes**: Kumpulan pesan hangat dan kutipan penuh makna.
- 📸 **Visual Slideshow**: Transisi foto estetik yang menampilkan kenangan favorit.
- 📱 **Responsive Design**: Tampilan nyaman diakses lewat ponsel maupun desktop.

---

## Rencana Pengembangan (Roadmap)

- [ ] **AI Companion (Chatbot)**: Chatbot interaktif dengan persona unik untuk teman ngobrol seru.
- [ ] **Photo Upload & Memory Timeline**: Fitur unggah foto langsung dari browser beserta catatan tanggal.
- [ ] **Interactive Letters**: Surat digital bersegel yang bisa dibuka pada momen atau tanggal tertentu.
- [ ] **Custom Playlists**: Pilihan lagu sesuai suasana hati (*mood-based soundtrack*).

---

## 🛠️ Teknologi

- **Frontend**: HTML5, CSS3, JS, Python
- **Audio & Media**: Web Audio API / HTML Audio Element
